# Brand logos
Drop official logo files here (SVG or PNG, square-ish, transparent background), named by brand in lowercase:
`apple.svg`, `samsung.svg`, `vivo.svg`, `oppo.svg`, `realme.svg`, `redmi.svg`, `oneplus.svg` ...
Then list the file names in `manifest.json`, e.g. `["apple.svg","samsung.svg"]`.
"iPhone" automatically uses `apple.svg`. Brands without a file show a monogram badge.
